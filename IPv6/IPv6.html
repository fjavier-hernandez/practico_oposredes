    IPv6¶

    IPv6 es la evolución del protocolo IPv4 y se diseñó para solventar sus limitaciones, especialmente la escasez de direcciones.

    IPv6: Características y Funcionamiento¶

    • Direcciones de 128 bits: Permite una cantidad casi ilimitada de direcciones IP (3.4×10³⁸ direcciones)
    • Formato hexadecimal: 8 grupos de 16 bits separados por : (ej: 2001:0db8:85a3:08d3:1319:8a2e:0370:7334)
    • Autoconfiguración (SLAAC): Asignación automática sin servidor DHCP
    • Encabezado simplificado: 9 campos frente a 13 de IPv4, mejor eficiencia
    • Seguridad integrada: IPSec obligatorio para cifrado y autenticación
    • Mejor QoS: Etiquetas de flujo para priorización
    • Sin NAT: Cada dispositivo puede tener dirección pública

    Tipos de direcciones IPv6¶

    Tipo Prefijo Equivalente IPv4 Uso
    Unicast Global 2000::/3 Públicas Internet global
    Unicast Link-Local FE80::/10 APIPA Comunicación en red local
    Unicast Unique Local FC00::/7 Privadas Redes internas
    Multicast FF00::/8 Broadcast Comunicación a múltiples destinos
    Anycast - - Ruteo al nodo más cercano

    Subnetting en IPv6: Conceptos Claves¶

    En IPv6, el subnetting es más sencillo y flexible que en IPv4 gracias al amplio espacio de direcciones (128 bits). Las asignaciones siguen convenciones estándar que facilitan la planificación de redes.

    Estructura General de una Dirección IPv6¶

    En IPv6, la estructura de la dirección se divide en tres partes principales cuando se realiza subnetting:

    Prefijo de red Subred ID de interfaz
    Global Prefix Subnet ID Interface ID
    GGGG:GGGG:GGGG SSSS XXXX:XXXX:XXXX:XXXX
    1. Prefijo de Red (Normalmente 48-56 bits)
    • Asignado por el ISP o RIR (Registro Regional de Internet)
    • Ejemplos comunes:
    • /48 para empresas (65k subredes disponibles)
    • /56 para redes residenciales (256 subredes)
    • /64 para enlaces individuales
    1. Campo de Subred (Variable, típicamente 16 bits en redes /48)

    • Permite crear jerarquías internas:

    • /48: Asignado por el ISP para empresas, permite 65,536 subredes /64.

    • /52: Subdivisión del bloque /48 para regiones específicas.
    • /56: Subdivisión del bloque /52 para sucursales o clientes residenciales.
    • /64: Subred estándar para enlaces LAN/WAN.
    1. ID de Interface (64 bits)
    • Generado automáticamente (SLAAC) o manualmente
    • Usa comúnmente EUI-64 (derivado de MAC)

    Tamaños de prefijo comunes en IPv6¶

    Prefijo Equivalente IPv4 Uso típico Capacidad
    /128 Dirección host Interface única 1 dirección
    /64 Subred estándar Por cada enlace LAN/WAN 18.4 quintillones direcciones
    /56 Bloque mediano ISPs a clientes residenciales 256 subredes /64
    /48 Bloque empresarial Empresas medianas/grandes 65,536 subredes /64
    /32 Bloque ISP Asignación a proveedores 65,536 subredes /48

    Estructura de la dirección IPv6¶

    Sección Bits Ejemplo
    Prefijo asignado 48 2001:db8:abcd::/48
    Subred interna 16 0001 (Ejemplo: 2001:db8:abcd:0001::/64)
    ID de interfaz 64 fe80::1a2b:3c4d:5e6f:7g8h

    Explicación¶

    • El ISP asigna un /48, lo que deja 16 bits para crear subredes.
    • Cada subred se identifica con 16 bits adicionales, permitiendo 65.536 subredes (0001, 0002, 0003, ... hasta ffff).
    • El host ocupa los últimos 64 bits, generados automáticamente con SLAAC o configurados manualmente.

    Ejercicio Resuelto: Subnetting IPv6 con VLSM¶

    Una empresa ha obtenido el prefijo 2001:DB8:ACAD::/48 y necesita dividir su red en varias subredes para sus diferentes departamentos. La empresa tiene los siguientes requisitos:

    1. Departamento de Informática: Requiere 5 subredes, cada una con al menos 500 hosts.
    2. Departamento de Administración: Necesita 4 subredes, cada una con 1000 hosts.
    3. Departamento de Profesorado: Requiere 2 subredes, cada una con 2000 hosts.
    4. Zona WiFi: Necesita una subred con al menos 4000 hosts.
    5. Enlaces punto a punto: Se requieren 5 enlaces entre routers, cada uno con 2 direcciones IP.

    Preguntas:¶

    3. Explicar cuántas direcciones se desperdician en cada subred.
    4. Justificar cómo se podría mejorar la eficiencia del direccionamiento.

    Note

    Subredes /64:
    - Capacidad: 18,446,744,073,709,551,616 direcciones cada una
    - Última dirección válida: [Prefijo]:FFFF:FFFF:FFFF:FFFE

    Enlaces P2P /127:
    - Solo 2 direcciones utilizables (xxx::0 y xxx::1)
    - Recomendado por RFC 6164 para enlaces punto a punto

    Numeración Hexadecimal:
    - Secuencia lógica: 0000-0004 (Informática), 0005-0008 (Administración), etc.
    - Enlaces usan rango FF01-FF05 para fácil identificación

    1. Desperdicio por subred: En IPv6, las subredes /64 son estándar, lo que significa que, aunque se necesiten pocos hosts, siempre se reservan direcciones.
