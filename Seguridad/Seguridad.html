    Seguridad

    Iptables¶

    Iptables es una herramienta de configuración de reglas de seguridad para el sistema operativo Linux. Permite controlar y filtrar el tráfico de red en función de criterios específicos.

    Tipos de Reglas¶

    Las reglas de iptables se clasifican en tres categorías:

    • Reglas de entrada: Controlan el tráfico que entra al sistema.
    • Reglas de salida: Controlan el tráfico que sale del sistema.
    • Reglas de redirección: Redirigen el tráfico entre interfaces o direcciones IP.

    Cadenas y Reglas¶

    Las reglas se agrupan en cadenas. Una cadena es una secuencia de reglas que se evalúan en orden. Las cadenas pueden ser:

    • Cadenas estándar: Cadenas predefinidas como INPUT, OUTPUT y FORWARD.
    • Cadenas personalizadas: Cadenas creadas por el usuario.

    Targets¶

    Un target es la acción que se tomará con un paquete que cumpla una regla. Los targets pueden ser:

    • ACCEPT: Permite el tráfico.
    • DROP: Rechaza el tráfico sin notificar al remitente.
    • REJECT: Rechaza el tráfico y envía un mensaje de rechazo al remitente.

    Comandos¶

    A continuación se presentan algunos comandos básicos para trabajar con iptables:

    Comando Función
    iptables -A Agrega una regla a una cadena.
    iptables -D Borra una regla de una cadena.
    iptables -R Reemplaza una regla en una cadena.
    iptables -I Inserta una regla en una cadena.
    iptables -L Muestra las reglas de una cadena.
    iptables -F Borra todas las reglas de una cadena.
    iptables -Z Pone en cero los contadores de una cadena.

    Targets Específicos¶

    A continuación se presentan algunos targets específicos:

    • MASQUERADE: Oculta la dirección IP del sistema y muestra la dirección IP de la interfaz por la que se está enviando el tráfico.
    • MARK: Asigna una marca a un paquete para identificarlo en la red.

    Cadenas Mangle¶

    La cadena MANGLE permite realizar operaciones avanzadas en los paquetes, como:

    • Cambiar la dirección IP o el puerto de un paquete.
    • Redirigir el tráfico entre interfaces o direcciones IP.

    Netfilter¶

    Netfilter es el kernel de iptables. Permite controlar y filtrar el tráfico de red en función de criterios específicos.

    Ejercicio de Oposiciones - Seguridad Informática: Configuración Básica con iptables¶

    Enunciado:

    Un servidor web de una pequeña empresa, con dirección IP privada 192.168.1.100 y conectado a Internet a través de una interfaz eth0 con dirección IP pública dinámica, necesita las siguientes reglas de firewall configuradas mediante iptables:

    1. Permitir el acceso al servidor web (puertos TCP 80 y 443) desde cualquier dirección IP externa.
    2. Permitir el acceso al servidor mediante SSH (puerto TCP 22) únicamente desde la red interna 192.168.1.0/24.
    3. Denegar todo otro tráfico entrante por defecto.
    4. Permitir todo el tráfico saliente originado desde el servidor.
    5. Configurar masquerading para que el servidor pueda acceder a Internet a través de su interfaz eth0.

    Escribe los comandos iptables necesarios para implementar estas reglas. Asume que la política por defecto para la cadena INPUT es DROP y para la cadena FORWARD es DROP.

    Solución:

    A continuación, se presentan los comandos iptables para configurar el firewall según los requerimientos:

    1. Permitir acceso web (TCP 80 y 443) desde cualquier origen:

      sudo iptables -A INPUT -i eth0 -p tcp --dport 80 -j ACCEPT
sudo iptables -A INPUT -i eth0 -p tcp --dport 443 -j ACCEPT
      • -A INPUT: Añade una regla al final de la cadena INPUT (tráfico entrante).
      • -i eth0: Especifica que la regla se aplica al tráfico que entra por la interfaz eth0.
      • -p tcp: Indica que la regla se aplica al protocolo TCP.
      • --dport 80: Especifica el puerto de destino 80 (HTTP).
      • --dport 443: Especifica el puerto de destino 443 (HTTPS).
      • -j ACCEPT: Indica que el tráfico que coincida con esta regla será aceptado.

    2. Permitir acceso SSH (TCP 22) solo desde la red interna:

      sudo iptables -A INPUT -i eth0 -p tcp --dport 22 -s 192.168.1.0/24 -j ACCEPT
      • -s 192.168.1.0/24: Especifica que la regla solo se aplica al tráfico originado desde la red 192.168.1.0/24.

    3. Denegar todo otro tráfico entrante por defecto (asumido en la política por defecto):

      No se necesita un comando explícito aquí, ya que se asume que la política por defecto de la cadena INPUT es DROP. Cualquier tráfico entrante que no coincida con las reglas anteriores será descartado.

    4. Permitir todo el tráfico saliente originado desde el servidor:

      sudo iptables -A OUTPUT -o eth0 -j ACCEPT
sudo iptables -A OUTPUT -o lo -j ACCEPT
      • -A OUTPUT: Añade una regla al final de la cadena OUTPUT (tráfico saliente).
      • -o eth0: Especifica que la regla se aplica al tráfico que sale por la interfaz eth0.
      • -o lo: Especifica que la regla se aplica al tráfico que sale por la interfaz de loopback. Es importante permitir el tráfico local.
      • -j ACCEPT: Indica que el tráfico que coincida con esta regla será aceptado.

    5. Configurar masquerading para acceso a Internet:

      sudo iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE
      • -t nat: Especifica que la regla se añade a la tabla nat (Network Address Translation).
      • -A POSTROUTING: Añade una regla al final de la cadena POSTROUTING, que se aplica después de que se ha decidido la ruta del paquete.
      • -o eth0: Especifica la interfaz de salida hacia Internet.
      • -j MASQUERADE: Realiza la traducción de direcciones, utilizando la dirección IP de la interfaz de salida (eth0).

    Nota:

    • Estos comandos deben ejecutarse con privilegios de superusuario (generalmente con sudo).
    • Esta configuración no es persistente a través de reinicios. Para guardar las reglas de forma permanente, se deben utilizar herramientas específicas de la distribución Linux (por ejemplo, iptables-save y iptables-restore en Debian/Ubuntu, o firewalld o nftables en sistemas más recientes).
    • Es importante entender el orden de las reglas en iptables. Las reglas se evalúan secuencialmente, y la primera regla que coincida con el tráfico determinará la acción a tomar.

    Este ejercicio aborda conceptos fundamentales de iptables como la manipulación de cadenas (INPUT, OUTPUT, POSTROUTING), el uso de interfaces (eth0, lo), protocolos (tcp), puertos (80, 443, 22), direcciones IP y redes (192.168.1.0/24), y el uso de targets (ACCEPT, MASQUERADE).
